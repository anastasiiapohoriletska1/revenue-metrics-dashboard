# revenue-metrics-dashboard

Interactive Tableau dashboard for tracking monthly revenue dynamics and analyzing the drivers behind changes in revenue and paid users.

**[View the dashboard on Tableau Public](https://public.tableau.com/views/RevenueMetricsDashboard_17855887352090/RevenueMetricsDashboard?:language=en-US&:sid=&:display_count=n&:origin=viz_share_link)**

# Tools

- **SQL (PostgreSQL)** for data extraction and aggregation
- **Tableau Public** for calculated fields, filters, and dashboard design

## Business Task

Build a dashboard that helps product managers monitor how revenue changes month to month and run a quick top-level analysis of what drives those changes.

## Metrics

| Metric | Definition |
|---|---|
| MRR | Monthly Recurring Revenue: revenue from recurring sources in a calendar month |
| Paid Users | Number of users who paid in a given month |
| ARPPU | Average Revenue Per Paid User = Revenue / Paid Users |
| New Paid Users | Users who made their first payment in a given month |
| New MRR | MRR generated by new paid users |
| Churned Users | Users who stopped paying in a given month |
| Churn Rate | Churned Users (current month) / Paid Users (previous month) |
| Churned Revenue | Previous month's revenue from users who stopped paying |
| Revenue Churn Rate | Churned Revenue (current month) / MRR (previous month) |
| Expansion MRR | MRR increase from users who started paying more |
| Contraction MRR | MRR decrease from users who started paying less |
| LT | Customer Lifetime: average time from first payment to churn |
| LTV | Customer Lifetime Value: average total revenue per user |

## Dashboard Features

- Month-over-month breakdown of revenue change factors: New MRR, Expansion, Contraction, and Churned Revenue
- Month-over-month breakdown of paid users change: new vs. churned users
- KPI overview of the key revenue metrics
- Interactive filters by date, user language, and user age
